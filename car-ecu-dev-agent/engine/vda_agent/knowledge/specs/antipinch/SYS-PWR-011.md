# SYS-PWR-011 电动车窗防夹系统需求（系统层，追溯至 SWE.1 软件需求）

- 功能：上升过程中检测到夹持物时，车窗应在 100ms 内反转下降，反转行程 ≥ 50mm。
- 安全目标：防止夹伤手指 / 颈部，避免人身伤害（ASIL B，ISO 26262）。
- 法规：GB 11552 / FMVSS 118 对夹持力上限的强制要求（峰值夹持力 ≤ 100 N）。
- 控制周期：防夹控制周期 10ms，端到端反应时间 ≤ 100ms（P99）。
- 接口：经 CAN 接收车窗开关命令并周期上报车窗状态（PwrWinSwCmd / PwrWinSts）。
- 保护：电机堵转时应停止驱动并进入受阻状态以保护电机。
